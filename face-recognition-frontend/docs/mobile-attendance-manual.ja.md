# モバイル版顔認証 操作マニュアル

「モバイル版顔認証」は、会社の業務用iPhoneで顔認証による出勤・退勤の打刻を行うためのアプリです。会社が管理する端末に、Intuneを通じて配付されます。

打刻画面上部の **マニュアル** をタップすると、打刻画面に重ねてこの説明が開きます。開くとカメラは停止します。確認後は、**打刻画面に戻る** または右上の **閉じる（×）** をタップしてください。カメラは **Start Camera** で再開できます。

## 基本の使い方

1. iPhoneのホーム画面で「モバイル版顔認証」を開きます。
2. 画面下の **Start Camera** をタップします。カメラの使用許可を求められた場合は、許可してください。
3. 画面上部の「ステータス」を確認します。打刻したい区分と異なる場合は、**出勤** または **退勤** をタップして選びます。
4. 自分の顔全体が映るようにiPhoneを持ち、カメラに正面を向けます。
5. 画面下の **打刻開始** をタップします。位置情報の使用許可を求められた場合は、許可してください。
6. **打刻中...** と表示されたら、そのまま顔を映して結果を待ちます。**「打刻成功：氏名 - 打刻時刻」** というメッセージが表示されたことを確認し、氏名と時刻が正しいか確かめてください。
7. 操作が終わったら、右上の **Stop** をタップしてカメラを停止します。

**Start Camera** はカメラを起動するボタンです。カメラを起動しただけでは打刻されません。必ず **打刻開始** をタップし、成功メッセージまで確認してください。

## 利用前に確認すること

- 会社から配付された、MDM管理下の業務用iPhoneを使用してください。「モバイル版顔認証」が見つからない場合は、管理担当者に確認してください。
- 顔認証を利用するには、ご自身の顔情報があらかじめ登録されている必要があります。未登録の場合や登録状況が分からない場合は、管理担当者に確認してください。
- 打刻には通信環境と、カメラ・位置情報の使用許可が必要です。会社の管理設定により許可を変更できない場合は、管理担当者に相談してください。
- アプリは打刻時に、顔画像、出勤・退勤の区分、端末の日時、位置情報をシステムに送信します。

## 出勤・退勤の選び方

端末の時刻に応じて、次の区分が自動で選ばれます。

| 端末の時刻 | 自動で選ばれる区分 |
| --- | --- |
| 04:00～14:59 | 出勤 |
| 15:00～翌03:59 | 退勤 |

出勤は青、退勤はピンクで強調され、画面上部にも選択中の区分が表示されます。自動選択は勤務予定を判断するものではありません。夜勤や通常と異なる時間帯に勤務する場合も、**打刻前に必ず区分を確認**してください。

区分は **出勤**・**退勤** ボタンで変更できます。手動で選んだ区分は約15分間維持され、その後は時刻による自動選択に戻ります。自動選択は約1分ごとに確認されるため、画面を開いたまま時間が経った場合は、もう一度区分を確認してください。

## 撮影と打刻のポイント

- 明るい場所で、顔に強い影や逆光がかからないようにしてください。
- 顔全体を画面の中央に映し、ほかの人の顔が映り込まないようにしてください。
- レンズが汚れている場合は拭き取り、顔がはっきり映ることを確認してください。
- **打刻開始** をタップした後、位置情報を取得してから顔画像を撮影します。位置情報の取得に時間がかかる場合もあるため、**結果が表示されるまで顔を映したまま待ってください**。
- 処理中はアプリを閉じたり、カメラを停止したりせず、結果を待ってください。

打刻が成功しても、カメラは起動したままです。結果を確認した後、必要に応じて **Stop** で停止してください。

## 「二重打刻の確認」が表示された場合

すでに同じ区分の打刻がある場合は、**二重打刻の確認** が表示されます。出勤・退勤の区分と「前回打刻時間」を確認してから操作してください。

| ボタン | 操作の結果 |
| --- | --- |
| **NO** | 今回の上書きを取りやめます。前回の打刻を残し、新しい打刻は記録しません。 |
| **YES** | 前回の打刻を今回の打刻で上書きする処理を行います。処理後の成功メッセージを確認してください。 |

すでに正しく打刻できている場合や、上書きしてよいか分からない場合は **NO** を選んでください。訂正が必要な場合は、社内の運用に従って管理担当者に確認してください。

## カメラの停止と再開

右上の **Stop** をタップすると、カメラが停止して表示が **Idle** に変わります。画面下には **Start Camera** が表示され、再びタップするとカメラを起動できます。

ボタン操作がないまま約10分経過すると、カメラは自動で停止します。打刻画面はそのまま表示されるため、次に利用するときは **Start Camera** をタップし、出勤・退勤の区分を確認してから打刻してください。

カメラの停止は、すでに完了した打刻を取り消す操作ではありません。

## 困ったときは

| 状況 | 確認・対応 |
| --- | --- |
| カメラが起動しない／「カメラ起動失敗」と表示される | カメラの使用が許可されているか確認してください。別のアプリでカメラを使用している場合は、その使用を終えてから再度お試しください。許可を変更できない場合や改善しない場合は、管理担当者に相談してください。 |
| 「地理位置取得失敗」と表示される | 位置情報の使用許可と端末の位置情報設定を確認してください。取得に時間がかかる場合は、位置情報を取得しやすい場所で再度お試しください。会社の管理設定で変更できない場合は、管理担当者に相談してください。 |
| 顔認証に失敗する | 顔の向き、明るさ、レンズの汚れ、ほかの人の映り込みを確認してください。顔が隠れている場合は、顔全体が映るように調整してください。失敗が続く場合は、顔情報の登録状況を管理担当者に確認してください。 |
| 通信エラーや「打刻失敗」と表示される | 通信状態を確認してください。成功メッセージを確認できなかった場合、打刻できているかは画面だけでは判断できません。繰り返し操作したり上書きしたりする前に、管理担当者に打刻状況を確認してください。 |
| 表示された氏名が自分と異なる／打刻内容を間違えた | 表示内容と操作した時刻を控え、管理担当者に連絡してください。自己判断で上書きを繰り返さないでください。 |
| カメラがオフになっている | **Start Camera** で起動できます。打刻する前に、出勤・退勤の区分も確認してください。 |

問い合わせる際は、**氏名、操作した日時、選んだ区分、表示されたメッセージ、どの操作で問題が起きたか** を伝えると、確認がスムーズです。氏名や打刻時刻が表示された場合は、その内容も併せて伝えてください。
